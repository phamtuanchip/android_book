# Learn Android From Scratch to Advanced: A Free Vietnamese Book for Java Developers

*40 chapters and 2 appendices, from installing Android Studio to Bluetooth, NFC and publishing on Google Play — with runnable sample code for every chapter.*

Many Android tutorials teach you to copy-paste a screen and stop there. This book is different: it assumes you already know **Java and basic OOP**, and takes you the whole way — from environment setup to architecture, testing, security, hardware, and shipping to the Play Store. **It is written in Vietnamese today; an English edition is planned.**

## Who it is for

- Java developers who want to move into Android
- Readers who know nothing about Android, Gradle or mobile concepts — setup is covered step by step
- Developers who need the deeper topics: inter-app communication, Bluetooth, NFC

You do not need to know Kotlin; the book is Java-first, with Kotlin coroutines as an extension.

## What is inside

- **Part 0 — Setup:** Android architecture, JDK, Android Studio, emulator and real device, first project, Hello World
- **Part 1 — Fundamentals:** Activity lifecycle, XML layouts and ConstraintLayout, Intents, Fragments and Navigation, RecyclerView, resources and localisation
- **Part 2 — Data storage:** SharedPreferences, SQLite and Room, file storage and scoped storage, Jetpack DataStore
- **Part 3 — Background work:** services, BroadcastReceiver, WorkManager, threads and coroutines, notifications
- **Part 4 — Networking:** OkHttp and Retrofit, JSON parsing, error handling, offline-first basics
- **Part 5 — Testing, sandbox and security:** JUnit, Espresso, the permission model, ProGuard/R8, keystores and signing
- **Part 6 — Advanced architecture:** MVVM, ViewModel and LiveData, Hilt dependency injection, Jetpack Compose, Clean Architecture
- **Part 7 — Inter-app and hardware:** Content Providers, deep links and share sheets, AIDL and bound services (IPC), Bluetooth Classic and BLE, NFC and Host Card Emulation
- **Part 8 — Publishing:** release builds and App Bundles, Google Play Console, Crashlytics and analytics

## How the book is built

Each chapter ships with sample code stored in the repository, so the examples are real projects, not loose snippets. The book is available as HTML and as a PDF of about 225 pages for offline reading.
